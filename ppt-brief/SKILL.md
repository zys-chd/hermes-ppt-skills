# PPT Brief — 需求访谈与完善

在做 PPT 之前，先用本 skill 把用户模糊的需求访谈清楚，产出一份"ppt-builder 可直接开工"的完整 brief。

## 什么时候用
- 用户说"帮我做个 PPT"但信息不全（没说主题 / 受众 / 有没有数据 / 什么风格）
- 用户给了初步信息，但还缺关键要素，直接生成容易跑偏
- 需要把口头需求转成结构化任务

## 工作流程
1. **接收**：拿到用户的初步信息（可能只有一句话）。
2. **盘点**：对照下方问题清单，标记哪些已知、哪些缺失。
3. **提问**：针对缺失的关键项，用 clarify 工具分批问（每批 3~5 个；风格/篇幅这类有选项的用多选，开放式问题让用户自由答）。
4. **补全**：用户回答后若仍有关键缺口再追问一轮；用户说"你定"的项用合理默认值并注明。
5. **产出 brief**：按下方模板输出结构化 brief，交给 ppt-builder。

## 问题清单（按优先级，只问缺失项，不重复问已知项）

### A. 主题与目的（必问）
- 主题：一句话说清要讲什么？
- 目的：汇报进度 / 评审方案 / 培训 / 提案 / 复盘 / 攻关报告？

### B. 受众（必问）
- 给谁看：技术专家 / 管理层 / 客户 / 混合？
- 他们最关心：技术细节 / 结论与决策 / 成本收益 / 风险？

### C. 风格与配色
- 风格：科技深色 / 极简留白 / 杂志图文 / 暖色商务 / 你来定？
- 配色：有没有从网站找到的配色？（给 1~3 个 hex 色值，交给 ppt-builder 用 expand_palette 拓展成完整色系）
  没有就由模型根据主题/受众自定。

### D. 内容与数据
- 有没有现成数据/材料（CSV/Excel/文档/图片）？路径或内容给我。
- 需要我帮你做哪些分析？
- 有没有必须嵌入的图片/物证/logo？

### E. 篇幅与结构
- 大概多少页？有没有硬性页数？
- 必须包含的章节/要素？（封面/摘要/某几个分析页/建议页…）

### F. 语言与格式
- 中文还是英文？
- 公司名/产品名/汇报人/日期？

## 提问原则
- 每批问 3~5 个最关键的问题，不要一次 10 个审问式轰炸。
- 用户已给的信息不重复问。
- 用户说"你定"的，选合理默认值，在 brief 里注明"（默认）"。
- 多选优先用 clarify 的 choices（≤4 选项），开放式用开放式提问。

## brief 产出模板（交给 ppt-builder）

```markdown
【任务描述】
（一段完整的话，作为 ppt-builder 的生成 prompt：主题 + 目的 + 受众 + 核心要求）

【数据与材料】
- 数据文件：<路径 或 "无，需自拟/需分析">
- 图片/物证：<路径清单 或 "无">

【风格与配色】
- 风格：<tech / minimal / editorial / warm / 自定>
- 配色：<基础色 hex 列表，交给 ppt-builder 用 expand_palette 拓展；或 "模型自定">

【结构要求】
- 页数：约 N 页
- 必备章节：<清单>

【其他】
- 语言 / 公司名 / 产品名 / 汇报人 / 日期
```

产出 brief 后，把它作为输入交给 ppt-builder（加载 ppt-builder skill）生成 PPT。
